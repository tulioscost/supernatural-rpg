# Tipografias locais

O tema tem estilos próprios para **Typernatural**, **I KNOW A GHOST**, **Go around the books 2022**, **Slender**, **i’mWeird** e **kindergarten**. A distribuição do sistema não redistribui os arquivos de fonte.

Caso tenha direito de utilizar essas fontes no seu ambiente, copie seus arquivos originais para `systems/supernatural-cacadores/assets/fonts/` ou instale-os no computador. Os nomes esperados estão declarados em `styles/supernatural.css`. Caso não instaladas, as fontes de reserva do navegador mantêm a ficha legível.
